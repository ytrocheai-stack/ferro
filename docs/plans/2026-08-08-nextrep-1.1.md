# NextRep 1.1 — plan de implementación

## Objetivo

Entregar una única versión estable con correcciones de datos y respaldos, catálogos USDA/wger/OFF, importación completa de Hevy, UI Technical Gradient sutil, rendimiento accesible y despliegue reproducible en GitHub Pages.

## Invariantes

- Se conservan la base Dexie `ferro`, los IDs existentes y la ruta `/ferro/`.
- Todo peso persistido permanece en kg; distancia en metros.
- La aplicación sigue funcionando sin backend ni autenticación propia.
- Los snapshots externos se versionan con licencia, origen, timestamp y hash.

## Orden de ejecución

1. Línea base, dependencias seguras y harness TDD.
2. Validación de respaldos, recálculo histórico, fechas y catálogo de alimentos.
3. Snapshots USDA/wger, API actual de Open Food Facts e importador Hevy CSV/API.
4. Virtualización, accesibilidad, Technical Gradient sutil y pruebas visuales.
5. Auditoría final, PR, Pages, documentación de instalación y release `v1.1.0`.

## Criterio de terminado

`npm run check`, auditoría de dependencias sin vulnerabilidades, pruebas WebKit/iPhone y Chromium/Android, flujo offline, importación idempotente/deshacer, respaldo v1/v2/v3 y URL pública instalable verificados.
