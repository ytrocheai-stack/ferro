## Reversión

El estado seguro actual es mantener `ENABLE_BETA=false` en
`worker/wrangler.production.toml` y desplegar esa configuración. Para recuperar
una versión anterior de código, usar un despliegue/version ID compatible de
Wrangler y comprobar después `GET /health`, readiness autenticado y el rechazo
de nuevos runs mientras la beta esté cerrada. Para revertir la PWA, crear un
commit de reversión en `main`, esperar el workflow de Pages y comparar
`version.json` con el SHA esperado. **No borrar ni revertir destructivamente
D1, migraciones, Vectorize, IndexedDB ni los identificadores `ferro`.**

La configuración anterior al cambio de modelo aún apunta a DeepSeek Flash,
que respondió HTTP 410; restaurar solo ese Worker no valida el respaldo ni
autoriza reabrir la beta.
